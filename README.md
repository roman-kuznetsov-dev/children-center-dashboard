# 📊 ERP-система для управления сетью детских развлекательных центров

Корпоративная система аналитики и управления для сети из 4 детских центров. Позволяет отслеживать продажи, анализировать выручку по клубам и категориям, формировать Z-отчёты и получать данные из касс через ОФД в реальном времени.

## 🎯 Возможности

- **Аналитика продаж** по 4 клубам с графиками и детализацией
- **6 категорий продаж**: праздники, мастер-классы, аквагрим, кафе, игрушки, входные билеты
- **Фильтрация по датам**: сегодня, текущий месяц, прошлый месяц, прошлая неделя, произвольная дата
- **Z-отчёт в Excel** с отдельным листом для каждого клуба
- **Ролевая модель**: 5 типов пользователей с разным уровнем доступа
- **Интеграция с ОФД** через Webhook (приём чеков от касс)
- **Автообновление** дашборда каждые 5 секунд

📊 Демонстрация

· Главная страница: KPI, графики, детализация по категориям

🔐 Роли пользователей

Роль Доступ

Руководитель (босс) Все 4 клуба + сравнение
